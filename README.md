🌱 Growvest – Investment & Chit Fund Management Platform

Growvest is a full-stack investment management platform built with React Native, Node.js, Express.js, and MongoDB. It enables users to invest in Savings Deposits, Fixed Deposits, and Chit Funds through a secure and modern mobile application while providing administrators with a powerful dashboard to manage users, investments, withdrawals, KYC verification, and transactions.

The application includes real-time investment tracking, automated payment verification (Razorpay integration), push notifications, secure authentication, KYC management, transaction history, monthly due management, and PDF statement generation, delivering a complete digital investment experience.
